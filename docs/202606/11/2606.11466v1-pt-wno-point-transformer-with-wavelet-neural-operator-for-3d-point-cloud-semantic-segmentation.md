## 摘要
点云语义分割需要能够同时捕获细粒度局部几何和广泛全局场景结构的架构。基于Transformer的网络通过聚焦于详细的局部特征聚合展现了强大的性能；然而，全局上下文主要通过编码器-解码器阶段之间的跳跃连接传递，我们认为这对于完整的场景理解是不够的。我们假设，通过一个可学习的全局特征提取模块增强跳跃连接，使得网络在深入局部细节之前能够获取场景级知识，从而产生更丰富、更具上下文基础的表示。为此，我们提出了结合小波神经算子的点Transformer（PT-WNO），它在点云Transformer主干的跳跃连接旁集成了一个共享的小波神经算子（WNO）分支。在每个编码器-解码器过渡处，点特征被投影到一个密集的三维体素网格上，其中WNO通过可学习的小波分解和重构捕获多尺度全局频谱上下文。这些全局特征通过轻量级的适配器融合回网络，补充而非替代现有的跳跃连接。在四个大规模三维点云基准上的实验证明了PT-WNO的有效性。在S3DIS（Area 5）上，PT-WNO达到了71.59%的mIoU，比Point Transformer v3（PTv3）基线高出+1.03个百分点。在DALES上，它达到了81.05%的mIoU（比基线高+1.47）。在ScanNet v2上，PT-WNO获得了76.19%的mIoU，与基线（76.36%）保持竞争力。

## Abstract
Point cloud semantic segmentation requires architectures that capture both fine-grained local geometry and broad global scene structure. Transformer-based networks have demonstrated strong performance by focusing on detailed local feature aggregation; however, global context is conveyed primarily through skip connections across encoder-decoder stages, which we argue is insufficient for full scene understanding. We hypothesize that augmenting skip connections with a learnable global feature extraction module allows the network to acquire scene-level knowledge before descending into local detail, leading to richer and more contextually grounded representations. To this end, we propose Point Transformer with Wavelet Neural Operato (PT-WNO), which integrates a shared Wavelet Neural Operator (WNO) branch alongside the skip connections of a point cloud transformer backbone. At each encoder-decoder transition, point features are projected onto a dense 3D volumetric grid where the WNO captures multi-scale global spectral context through learnable wavelet decomposition and reconstruction. These global features are fused back into the network via lightweight adapters, complementing rather than replacing the existing skip connections. Experiments on four large-scale 3D point cloud benchmarks demonstrate the effectiveness of PT-WNO. On S3DIS (Area 5), PT-WNO achieves 71.59% mIoU, outperforming the Point Transformer v3 (PTv3) baseline by +1.03 points. On DALES it achieves 81.05% mIoU (+1.47 over the baseline). On ScanNet~v2, PT-WNO obtains 76.19% mIoU, remaining competitive with the baseline (76.36%).

## 1. 核心问题与研究动机

- **研究背景**：三维点云语义分割需要同时捕捉细粒度局部几何与广泛的全局场景结构。现有基于 Transformer 的网络（如 Point Transformer v3）通过串行化局部窗口注意力实现了高效局部推理，但全局上下文主要依赖编码器-解码器之间的跳跃连接隐式传递。作者认为这种隐式方式不足以实现完整的场景理解，尤其对于大尺度室内外场景中的长程依赖关系。
- **核心问题**：如何显式、高效地建模点云的全局和多尺度空间结构，并融入局部 Transformer 主干，以提升分割性能？
- **假设**：在跳跃连接旁增设一个可学习的全局特征提取模块，使网络在深入局部细节前先获取场景级知识，能产生更丰富的上下文表示。

## 2. 方法论：核心思想与关键技术

- **总体架构**：PT-WNO 是一个双通路架构，由串行化点 Transformer 主干（基于 PTv3）和共享的 Wavelet Neural Operator（WNO）分支组成。WNO 分支在所有编码器-解码器过渡阶段处理点特征，提供明确的全局上下文。

- **主要流程**：
  1. **串行化与局部编码**：将原始点云通过空间填充曲线（如 Hilbert 码）映射为 1D 序列，进行分窗自注意力，得到局部特征。
  2. **网格投影**：在每个激活的编码阶段，将当前点特征通过轻量适配器投影到共享的通用通道维度，并通过归一化线性映射体素化为固定分辨率（64³）的稠密 3D 网格。落入同一体素的点特征做平均池化。
  3. **相对位置编码**：在网格化前，为每个点计算相对于该阶段点云中心的偏移和半径，归一化后通过小 MLP 生成位置嵌入，加到点特征上，以保留空间几何关系（跨场景尺度不变）。
  4. **小波神经算子（WNO）**：将体素化后的张量视为连续函数的离散化，WNO 核心算子进行如下操作：
     - 使用**可训练的分组深度可分离卷积**代替固定的小波滤波器，实现层次化多尺度分解（分析阶段）。
     - 对分解出的近似子带和细节子带系数应用可学习的 1×1×1 卷积进行特征混合。
     - 使用可训练的转置卷积进行重建（合成阶段），再加上局部旁路连接以保留高频细节。
     - 输出重构后的稠密网格，携带全局多尺度谱上下文。
  5. **网格-点提升**：每个点通过体素索引从输出网格中查找对应特征，经过适配器投影回主干通道维度，得到全局特征。
  6. **特征融合**：将全局特征与主干局部特征进行拼接、线性投影和非线性激活（LayerNorm + GELU），替代原主干特征，并通过标准跳跃连接传入解码器。

- **损失函数**：交叉熵损失 + Lovász-Softmax 损失（直接优化 mIoU 代理），整个模型端到端训练。

## 3. 实验设计

- **数据集与场景**：
  - **S3DIS (Area 5)**：室内场景（13 类），体素分辨率 0.02 m。
  - **DALES**：大规模室外航空 LiDAR 数据集（8 类），体素分辨率 0.05 m，移除颜色增强以测试纯几何推理。
  - **ScanNet v2**：室内 mesh 扫描（20 类），用于评估迁移性。
- **评价指标**：mIoU（主要）、mAcc、OA。
- **对比方法**：主流代表性方法包括 PointNet++、SPG、ConvPoint、KPConv、MinkUNet、SPT 等，核心基线是 **PTv3**（Reproduced under identical constraints）。
- **实验协议**：为确保公平，所有 PTv3 基线和 PT-WNO 变体均在同一硬件、超参数和随机种子下从头训练，性能差异仅归因于 WNO 分支。
- **主要结果**：
  - S3DIS (Area 5)：mIoU 71.59%（+1.03 vs. reproduced PTv3 70.56%），OA 91.28%，mAcc 76.9%。

## 6. 主要结论与发现

- PT-WNO 通过在点 Transformer 主干中显式加入全局小波算子，有效提升了点云语义分割性能，尤其在几何结构明显、颜色信息匮乏的室外 LiDAR 场景（DALES 提升 +1.47 mIoU）和室内复杂结构类别（如柱子、沙发等）上表现突出。
- 在密集 mesh 室内场景（ScanNet v2）中，WNO 分支未带来显著增益，但也没有退化，说明其作为几何互补模块的鲁棒性。
- 颜色移除消融实验表明，WNO 能够有效捕获纯几何上下文，适用于外观贫乏的 LiDAR 数据。
- 整体验证了“将全局上下文视为可学习算子”这一设计范式的有效性。

## 7. 优点

- **思路新颖**：首次将神经算子（特别是 Wavelet Neural Operator）系统地引入点云 Transformer 用于语义分割，开辟了新的设计空间。
- **设计合理**：在保持 PTv3 高效局部推理的同时，通过共享的全局算子补充全局信息，且不替换原有跳跃连接，易于集成。
- **泛化性验证**：在室内（S3DIS）、密集室内 mesh（ScanNet）、室外航空 LiDAR（DALES）三种完全不同类型的场景上均进行了测试，展示了通用性。
- **可学习小波算子**：用可训练的深度可分离卷积替代固定小波滤波器，使得分解基适应点云分割任务，提高了灵活性。
- **相对位置编码**：在网格化前加入归一化位置编码，保证了跨场景几何信息的尺度不变性。
