## 摘要
本文提出了一种针对S23DR Challenge 2026的竞争性解决方案，该挑战旨在从稀疏SfM点云以及地面级别的语义分割和深度图中重建3D房屋屋顶线框模型。我们的方法采用受DETR启发的端到端Transformer编码器-解码器架构。为了有效处理几何和语义数据，稀疏SfM点云输入基于语义优先级进行动态子采样，并增加了Gestalt和ADE20k类特征。为了进一步增加分割上下文，我们将点特征与额外的Gestalt特征编码融合，这些编码是通过将点投影到由冻结自编码器生成的潜在特征图中获得的。然后通过交叉注意力机制将学习到的查询嵌入直接解码为3D线框边缘。在“HoHo 22k”数据集上的评估表明，我们的方法显著优于手工制作和学习的基线方法，达到了0.6476的混合结构分数（HSS），并在挑战的私人排行榜上获得了第二高的位置。

## Abstract
This paper presents a competitive solution to the S23DR Challenge 2026, which aims to reconstruct 3D house roof wireframe models from sparse SfM point clouds and ground-level semantic segmentations and depth maps. Our proposed method utilizes an end-to-end Transformer encoder-decoder architecture inspired by DETR. To effectively process the geometric and semantic data, the sparse SfM point cloud input is dynamically subsampled based on semantic priority and augmented with Gestalt and ADE20k class features. To further increase segmentation context, we fuse the point features with additional Gestalt feature encodings which are obtained by projecting the points into latent feature maps produced by a frozen autoencoder. Learned query embeddings are then decoded directly into 3D wireframe edges via cross-attention mechanisms. Evaluated on the "HoHo 22k" dataset, our approach significantly outperforms both handcrafted and learned baselines, achieving a Hybrid Structure Score (HSS) of 0.6476 and securing the second-highest position on the challenge's private leaderboard.

## 2. 论文提出的方法论

### 核心思想
- 采用**DETR风格的Transformer编码器-解码器**架构，将点云点作为输入，使用一组可学习的查询（query）直接解码出3D边缘（两个端点坐标及分类）。
- 通过**语义优先级子采样**保留关键点（如边缘和顶点类点），并融合**Gestalt自编码器**提取的局部上下文特征，增强稀疏点云的语义感受野。

### 关键技术细节
1. **预处理与特征构建**
   - 将每个3D点投影到其所属的所有视图中，通过多数投票确定Gestalt和ADE20k类，并做one-hot编码（维度28+149=177），再加上RGB颜色（归一化），得到D=180维特征。
   - 点云子采样：对Gestalt边缘类和顶点类分别赋予10倍和100倍的采样权重，排除“未分类”和“未知”类，固定采样点数Np=7168。
   - 坐标归一化到单位立方体。

2. **网络架构**
   - **Transformer编码器**：将输入特征投影为De=360维嵌入，加上固定位置编码（基于点坐标），经5层编码器处理。
   - **Transformer解码器**：使用Nq=100个可学习查询（代表潜在边缘），通过自注意力（边缘间）和交叉注意力（边缘与点云）机制，经5层解码器后输出分类头（线性层）和坐标头（小MLP+sigmoid）。
   - 分类头只预测一个有效边缘类+背景类；坐标头输出两个端点的6个归一化坐标。

3. **局部Gestalt特征融合**
   - 训练一个**冻结的Gestalt自编码器**，将每个Gestalt图像编码为32×32×32的潜在特征图。
   - 子采样后，将每个点投影到各视图，在特征图中提取对应32维向量，通过共享线性层投影到De维，并加上相机中心与点间的相对方向位置编码，再通过视图平均和另一线性层，得到最终局部Gestalt特征。
   - 该特征与原始点特征通过可学习的权重（初始化为0）相加，然后送入编码器，逐步融入全局信息。

4. **损失函数**
   - 使用**匈牙利算法**匹配预测边缘与真值边缘，匹配代价为：分类负对数概率 + μ×L1距离（取原边与反向边的最小值，μ=5）。
   - 总损失 = 加权交叉熵损失（边缘类权重1，背景类0.1） + λ×L1损失（λ=5）。
   - 损失应用于每个解码器层的输出并求和。

5. **后处理**
   - 剔除背景类预测和置信度<0.95的边缘。
   - 迭代合并顶点：若两个不同边缘的端点距离<0.5米，则用其平均位置替代，直到无近邻对。同一根边的两个端点不合并。
   - 移除重复的边。

6. **推理增强**
   - 测试时增强（TTA）：对4个旋转角度（0°,120°,240°,300°）及水平翻转，共14种变换。
   - 模型集成：两个独立训练检查点的结果平均。
