## 摘要
真实世界的数据跨越表格、文档和具有隐式语义的半结构化文件。查询这些数据需要整合跨不一致模式和格式的证据，但现有方法要么需要昂贵的手动工程，要么完全绕过结构。我们提出一个系统，它从原始多源数据中自动发现可执行模式，并将其用作知识图谱构建和查询时检索的共享合同。闭合世界字段目录将基于LLM的模式发现限制在已证实的字段上；确定性结构分析推断身份键、外键和源层次结构；由此产生的模式驱动提取、去重和跨源链接，形成一个具有溯源意识的知识图谱。在查询时，模式（可选地通过单调协议扩展）条件化一个多工具代理，该代理在结构化查找、图遍历和向量搜索之间路由检索，返回带有可追溯引用的基础答案。在零样本比较中，使用相同的LLM、数据和评估框架，系统在四个QA基准测试上优于仅检索和基于分解的基线，消融实验表明模式条件化路由、结构智能和模式引导构建各自贡献了性能提升。

## Abstract
Real-world data spans tables, documents, and semi-structured files with implicit semantics. Querying this data requires integrating evidence across inconsistent schemas and formats, yet existing approaches either demand costly manual engineering or bypass structure entirely. We present a system that automatically discovers an executable schema from raw multi-source data and uses it as a shared contract for knowledge graph construction and query-time retrieval. A closed-world field catalog constrains LLM-based schema discovery to attested fields; deterministic structural analysis infers identity keys, foreign keys, and source hierarchy; and the resulting schema drives extraction, deduplication, and cross-source linking into a provenance-aware knowledge graph. At query time the schema -- optionally extended via a monotonic protocol -- conditions a multi-tool agent routing retrieval across structured lookup, graph traversal, and vector search, returning grounded answers with traceable citations. In controlled zero-shot comparisons using the same LLM, data, and evaluation harness, the system improves over retrieval-only and decomposition-based baselines across four QA benchmarks, with ablations showing that schema-conditioned routing, structural intelligence, and schema-guided construction each contribute to the gains.

- **背景**：现实世界的数据往往分散在表格、文档、JSON日志、Wiki等异构来源中，且具有隐式语义和不一致的标识符。组织依赖问答系统从这些混合数据中提取价值（例如“哪个产品在X公司2018年收购后推出，该年利润如何？”）。
- **核心问题**：现有方法要么需要昂贵的手动模式设计（如预定义实体类型、关系、提取规则），要么完全绕过结构（如纯向量检索），导致跨源连接、多跳检索和可追溯性失败。系统难以可靠地对齐实体、遍历关系或跨源证明答案。
- **整体目标**：实现无需手动设计的、自配置、自扩展的异构多源问答，同时保持低延迟、可控性和可审计性。

## 2. 论文提出的方法论：核心思想、关键技术、公式/算法流程

- **核心思想**：自动从原始异构数据中发现一个统一的“可执行模式”（Executable Schema Contract），并将其作为共享契约，同时驱动离线知识图谱（KG）构建和在线问答（QA）检索。该模式约束LLM的发现、指导实体链接，并用于查询路由。
- **关键技术**：
  - **闭世界字段目录（Closed-World Field Catalog）**：先对每个源进行剖析，枚举所有可观测字段（带哈希ID、类型、空值率、示例值）。LLM只能引用这些已存在的字段ID，防止幻觉。通过 `FieldValidity` 公式（引用ID与目录ID集的重叠比例）验证。
  - **统计结构智能（Statistical Structural Intelligence）**：无需LLM，通过确定性方法推断身份键（唯一性比率+命名模式）、外键（字段值重叠）、源层次（基数+行数比）。公式：`overlap = |V_fA ∩ V_fB| / max(|V_fA|, |V_fB|)` 等。
  - **两阶段LLM发现**：对每个源进行两次LLM调用——第一次深度分析代表性样本，第二次验证多样性样本，合并输出。
  - **模式驱动的KG构建**：根据模式中的属性映射、身份键、外键，执行提取、去重（基于键的O(n)哈希或嵌入聚类）、跨源链接和溯源（每个节点连接到SourceRecord）。
  - **查询时模式扩展**：通过单调协议（只增不减）按需扩展模式，分为持久扩展（全流程）和查询作用域扩展（单次LLM调用）。
  - **模式条件化路由**：QA代理初始化时分析模式，构建运行时路由上下文（字段类型分区、实体关系词汇、已知值字典）。路由顺序：SCHEMA LOOKUP（离散值约束）→ VECTOR RAG（非结构化证据）→ EXTERNAL SEARCH（OOD）。采用两阶段可靠性门控（预检索OOD检测+后检索接地验证），复合置信度 `c = c_link * c_node * c_ground`。
- **算法流程**：见附录A（Schema生成管道）、附录B（KG摄取）、附录D（QA代理）。大致步骤：源发现→剖析→字段目录→采样→两阶段LLM发现→结构分析→跨源链接→统一模式→模式驱动KG构建→查询时间扩展→模式条件化路由→答案合成。

## 7. 优点

- **创新性**：首次提出“可执行模式合同”，将模式发现、KG构建和查询路由统一在同一结构下，解决了异构问答的多个瓶颈。
- **可执行性保障**：闭世界字段目录防止LLM幻觉字段，统计结构分析避免LLM对基数、唯一性等的高错误率，两者结合保证了模式的可靠性。
- **低人工成本**：完全自动化，无需手动标注或模式设计，适应源变化。
- **可追溯性**：每个实体和答案均连接到源记录（DERIVED_FROM），支持审计。
- **模块化设计**：各组件（模式发现、KG构建、扩展、路由）可独立替换或消融，便于分析和改进。
- **实验设计严谨**：控制复现、消融、跨模型、延迟分析等多维度评估，且明确排除黄金标注防止数据泄露。
- **开源友好**：论文提供详细算法描述和伪代码，促进可复现性。
