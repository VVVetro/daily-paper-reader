## 摘要
对于轮椅使用者来说，地图上的一条标准蓝线往往是一个无法兑现的承诺。虽然像OpenStreetMap（OSM）这样的平台成功捕捉了路径的位置，但它们经常无法传达在其上行走时的体感。这种信息障碍对轮椅使用者来说是个问题。为了解决这个问题，我们提出了OmniPath，一个从被动映射转向主动环境审计的系统。我们的框架将OSM的网络拓扑与高密度机载LiDAR（USGS 3DEP）的亚米级精度相融合，创建了行人环境的高保真3D模型。不同于简单地给用户规划路线，我们的智能体实际上在网络上虚拟遍历，以0.5米为增量分析路面。它严格量化物理摩擦点——具体包括坡度、横坡和垂直不连续性——并与ADA合规标准比对，计算加权严重性评分，将危害分类为“轻微”到“严重”。为了确保现实世界的可靠性，我们采用分层随机抽样，在国家广场区域通过200次实地地面真值调查验证了系统。该框架在高度严重危害方面表现出强大的诊断可靠性，在严重和危急类别上分别达到0.60和0.58的F1分数。通过自动化的微观检查，OmniPath识别出标准地图遗漏的“无形”障碍，有效将静态数据集转化为可在用户离家前预测可达性挑战的可达性数据源。

## Abstract
For a wheelchair user, a standard blue line on a map is often a broken promise. While platforms like OpenStreetMap (OSM) successfully capture where a path is, they frequently fail to convey how it physically feels to travel on it. This information barrier is problematic for wheelchair users. To solve this issue, we present OmniPath, a system that moves from passive mapping to proactive environmental auditing. Our framework fuses the network topology of OSM with the submeter precision of high-density aerial LiDAR (USGS 3DEP) to create a high-fidelity 3D model of the pedestrian environment. Rather than simply routing a user, our agent virtually traverses the network, analyzing the surface in 0.5 meter increments. It rigorously quantifies physical friction points specifically running slope, cross slope, and vertical discontinuities against ADA compliance standards, calculating a weighted severity score to categorize hazards from ``Mild'' to ``Critical.'' To ensure real world reliability, we validated the system against 200 physical ground truth field surveys across the National Mall using stratified random sampling. The framework demonstrated strong diagnostic reliability for high-severity hazards, achieving F1-scores of 0.60 for Severe and 0.58 for critical categories. By automating this micro-scale inspection, OmniPath identifies the ``invisible'' barriers that standard maps miss, effectively transforming a static dataset into accessibility data source that anticipates accessibility challenges before the user ever leaves home.

- **核心问题**：现有地图（如 OpenStreetMap）仅能提供路径的位置信息（“where”），但无法传达路径的物理体感（“how”），例如坡度、路面平整度、障碍物等。对于全球约6500万轮椅使用者而言，这些“微观障碍”（micro-barriers）比路径长度更重要，可能导致实际路径不可通行（例如一段看似可走的路线实则因4级台阶而阻断）。传统导航系统依赖用户众包报告或2D矢量数据（如DC-GIS将少于5级的台阶编码为普通人行道），存在数据稀疏性（无人报告即不可知）和语义泛化导致的“可达性陷阱”。
- **研究动机**：从被动式地图反映转向主动式环境审计，在用户出发前提前预测并量化无障碍性摩擦。
- **总体含义**：OmniPath 将静态2D地图转换为动态3D可达性审计工具，通过融合异构数据、自主遍历网络、按ADA标准逐段评分，揭示“无形”障碍。

## 2. 方法论：核心思想、关键技术细节、公式与算法流程
### 2.1 核心思想
- **范式转变**：从“被动收集用户报告”转向“主动环境审计”。系统虚拟遍历整个道路网络，以亚米级精度分析路面几何特征，无需用户实际到场。
- **多模态融合**：将OSM的2D拓扑网络与USGS 3DEP机载LiDAR高密度点云（点密度≥8点/m²，垂直精度±5-10 cm）融合，构建高保真3D行人环境模型。

### 2.2 关键技术细节
- **微尺度分割**：将每条路边段离散为0.5米长的非重叠滑动窗口（近似手动轮椅的轮距），在每个窗口内关联对应的LiDAR点云子集。
- **特征提取**：在每个0.5米窗口内计算三个关键几何指标：
  - **运行坡度（Running Slope）**：沿行进方向的高程变化率，ADA最大允许8.33%（1:12），超过则为障碍。
  - **横坡（Cross Slope）**：垂直于行进方向的坡度，ADA最大2%（1:48），过大导致轮椅侧向漂移。
  - **垂直不连续性（Discontinuity）**：窗口内最大垂直高程变化，ADA规定>13mm即不合规，>20mm标记为严重“卡轮”风险。
- **加权严重性评分（Weighted Severity Score, S）**：
  - 先计算比例超限值：\( E = \max\left(0, \frac{\text{实测值} - \text{阈值}}{\text{阈值}}\right) \)，阈值分别为运行坡度8.33%、横坡2.0%、不连续2.0 cm。
  - 再加权求和：\( S = (E_{\text{running}} \times 4.0) + (E_{\text{cross}} \times 2.5) + (E_{\text{disc}} \times 3.5) \)。权重基于生物力学风险：运行坡度影响推进力和前倾风险（最高），不连续导致卡轮和失稳（次高），横坡造成不对称疲劳（最低）。
- **四级严重性分类**：
  - 轻微（Mild, S<0.5）：可通行，无阻抗。
  - 中等（Moderate, 0.5≤S<1.5）：需注意，标记为警戒区。
  - 严重（Severe, 1.5≤S<3.0）：高阻抗，主动绕行。
  - 危急（Critical, S≥3.0）：不可通行，直接裁剪出网络。

### 2.3 算法流程（文字描述）
1. **数据获取与对齐**：从OSM提取国家广场区域1485条路径段；从USGS 3DEP获取2021年DC机载LiDAR点云；通过投影坐标系统（CRS）对齐两个数据源。
2. **几何感知引擎（Agent A）**：以0.5米滑动窗口（步长0.25米）遍历每条路径，在每个窗口内查询LiDAR点云，计算上述三个几何指标。
3. **语义审计与阻抗映射**：根据加权评分S将每个窗口分类为四个等级之一，为路由引擎提供段级阻抗值。
4. **宏观特征识别（辅助分析）**：用2.0米窗口检测楼梯（连续垂直变化8-25 cm，踏步长15-45 cm）和吊顶结构（点云双峰分布）。

## 6. 主要结论与发现
- **高危障碍普遍存在**：在可分析的97段路径中，95段（97.9%）被分类为“危急”或“严重”，平均每个段含3.41个违规，77.3%的段存在复合障碍。
- **横坡是主要失效模式**：横坡违规占比最大（多数段不达标），而运行坡度大多合规。横坡、不连续性构成严重违规的主要驱动力。
- **地理聚集性**：高危障碍集中在主要行人大道和纪念路线，而非随机分布，支持针对性修复策略。
- **检测性能**：严重和危急级别的F1分数分别为0.60和0.58，中等为0.50，轻微为0.33，证明系统对高危障碍检测可靠，但对轻微偏差精度低。
- **传统GIS数据的缺陷**：DC-GIS将少于5级的台阶编为人行道，导致可达性陷阱；OmniPath的3D审计可识别此类隐含障碍。

## 7. 优点
- **主动审计范式**：无需用户报告即可预测障碍，拓展无障碍数据的覆盖范围。
- **精细粒度**：0.5米窗口匹配轮椅轮距，捕捉被平均化抹去的局部障碍。
- **部分加权机制**：基于生物力学风险的权重赋予，使分级具有身心健康意义。
- **多数据源融合**：巧妙融合OSM拓扑与LiDAR地形，实现“意图+现实”的双层验证。
- **实际验证合理**：使用分层抽样确保高危样本充足，验证方法科学。
- **可扩展性**：传感器无关设计，未来可集成移动LiDAR或街景图像；明确规划了Agent B语义模块（YOLOv8+Mapillary）。

## 8. 不足与局限

- **消融实验缺失**：未评估0.5米窗口大小、步长、权重系数等超参数的影响，也未分析不同LiDAR点密度对结果敏感度。

- **计算与实时性未知**：未讨论处理303,361个窗口所需的时间与计算资源，也未提及能否支持实时路由。
