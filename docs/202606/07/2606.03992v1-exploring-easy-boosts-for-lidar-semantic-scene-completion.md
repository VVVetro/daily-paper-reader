## 摘要
本文研究“免费午餐”策略，无需复杂架构重新设计即可提升激光雷达语义场景补全（SSC）性能。我们首先证明，将现成分割器的语义伪标签赋予输入点云显著提升现有架构性能。通过与Oracle对比评估，我们确定高质量语义先验是mIoU提升的主要驱动力。此外，我们为输入激光雷达扫描配备区分空域和未知空间的可见性信息，这为测试架构提供了二次性能提升。使用这些简单增强，我们观察到旧模型与最先进系统仍具竞争力，甚至能够超越它们。我们的代码开源在https://github.com/astra-vision/SSC-Priors。

## Abstract
This paper investigates "free lunch" strategies to boost the performance of lidar semantic scene completion (SSC) without requiring complex architectural redesigns. We first demonstrate that endowing input point clouds with semantic pseudo-labels from off-the-shelf segmentors significantly improves the performance of existing architectures. By evaluating these models against an oracle, we establish that high-quality semantic priors are a primary driver of mIoU gains. Furthermore, we equip the input lidar scan with visibility information that distinguishes between empty and unknown spaces, which provides a secondary performance boost across the tested architectures. Using these simple enhancements, we observe that older models remain competitive with state-of-the-art systems, and can even outperform them. Our code is available at https://github.com/astra-vision/SSC-Priors.

- **研究问题**：激光雷达语义场景补全（Lidar Semantic Scene Completion, SSC）任务中，现有方法依赖复杂架构设计，但性能增益的来源不明确。作者希望探究是否可以通过简单、即插即用的输入增强策略，在不修改网络架构的前提下显著提升SSC性能。

## 2. 论文提出的方法论：核心思想与关键技术细节

### 核心思想
- 将输入点云增强为**语义化点云**（通过现成分割器生成伪标签）和**可见性信息**（区分空、未知、占据体素），构建一个4D输入张量 `V ∈ {0,1}^{X×Y×Z×(C+2)}`（C为语义类别数，2为empty和unknown通道），然后直接喂入任何SSC网络，无需修改架构（仅调整输入层通道数）。

### 关键技术细节
1. **语义先验**：
   - 对每个体素，若包含激光雷达点，则通过多数投票分配语义伪标签（来自WaffleIron或MinkUNet等现成分割器）；否则标记为unknown。
   - Oracle实验中使用真实标签验证理论上限。
2. **可见性先验**：
   - 对每个激光雷达点，从传感器中心沿射线以δ=20cm间隔采样点，标记为empty。
   - 为减少离散化伪影，在占据体素的5×5×5邻域内设置“安全边际”并将这些体素标记为unknown（即使被射线穿过）。
   - 最终每个体素被分为empty、occupied（带语义）、unknown三类。
3. **组合策略**：
   - 将语义伪标签（或Oracle标签）与可见性信息合并到输入张量中，作为网络的额外输入通道（C+2），网络其余部分保持不变。

## 6. 主要结论与发现

1. **语义先验是主要性能提升因素**：使用Oracle语义标签可带来+13.8~+16.3 mIoU的巨大提升（Table 1），使用现成分割器伪标签可获得+5.1~+9.6 mIoU的显著提升。
2. **可见性先验提供补充增益**：单独使用可见性先验可提升IoU最高2.4点、mIoU最高1.0点；与语义先验组合时仍保持互补（即使在Oracle语义下仍有额外收益，如SemCity-AE +0.8 mIoU）。
3. **旧模型经增强后可与SOTA竞争**：SSA-SC + 我们的方法达到28.8 mIoU，超越DiffSSC和DPS2CNet（均为26.7 mIoU）。LMSCNet-SS和SemCity-AE也显著提升。
4. **语义瓶颈是当前SSC架构的主要限制**：Oracle语义可实现40.1 mIoU（SSA-SC），表明几何完成并非主要瓶颈，未来随着分割器进步，SSC性能可“免费”继续上涨。
5. **即插即用，无需重新训练**：仅修改输入通道数，不改变网络内部结构，成本极低。
